# APIWatch

A lightweight Python toolkit for API monitoring, testing, validation, and performance tracking.

APIWatch helps developers monitor REST APIs, measure response times, validate JSON responses, track API history, handle retries, and export monitoring reports.

---

## Features

- HTTP API monitoring
- Synchronous and asynchronous requests
- Response time measurement
- HTTP status code tracking
- Automatic retries with exponential backoff
- Configurable timeout, headers, and parameters
- JSON Schema response validation
- API response assertions
- In-memory history tracking
- SQLite persistent history
- API statistics
- Logging to console and files
- JSON and CSV report exports
- Command-line interface
- Synchronous and asynchronous context managers

---

## Requirements

- Python 3.10+
- HTTPX
- Pydantic 2.x
